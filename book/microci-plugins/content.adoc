== MicroCI Plugins

This chapter documents the plugins available in microCI.

The goal is to keep the main microCI chapter focused on concepts and workflow,
while this chapter serves as a detailed reference for implementation details.

=== Plugin overview

microCI plugins extend the same pipeline model to different targets and tasks.

* xref:microci-plugins#raspberry-pico[raspberry_pico] — Raspberry Pi Pico family builds and deployment
* xref:microci-plugins#shell[shell] — execute shell commands
* xref:microci-plugins#other-plugins[other plugins] — additional helpers and integrations
